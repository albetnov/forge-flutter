# `Schema` declaration

Immutable DDL description. Everything is `const`; DDL is generated by
`toCreateTableSql()` / `toSql()` / `toCreateSql()`. Import from
`package:sqlite_schema_forge/sqlite_schema_forge.dart`.

```dart
const appSchema = Schema(version: 2, tables: [
  Table('wallets', [
    Column.id(),
    Column.text('name', nullable: false),
    Column.integer('wallet_type_id', nullable: false),
    Column.integer('is_deleted', nullable: false, defaultValue: 0),
    Column.datetime('created_at', defaultValue: RawSql.currentTimestamp),
  ], indexes: [Index(columns: ['wallet_type_id'])]),
], virtualTables: [...], triggers: [...]);
```

## Configuration

| Type | Config |
| --- | --- |
| `Schema(version:, tables:, virtualTables:, triggers:)` | `version` is the `PRAGMA user_version` target. `virtualTables`/`triggers` default `[]`. |
| `Column.id/.text/.integer/.real/.datetime` | `id()` = `INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL`. `nullable` defaults `true`; add `unique`, `defaultValue`, FK via `refTable/refCol` (integer only). `datetime` is `TEXT` storage. |
| `RawSql` | Verbatim default/expression (`currentTimestamp/currentDate/currentTime`, custom `RawSql('...')`). `String` defaults are single-quoted, others inline. |
| `Index({name, columns, unique})` | Name defaults to `idx_<table>_<cols>` (`uniq_...` when unique). `toSql(table)` emits `CREATE [UNIQUE] INDEX IF NOT EXISTS`. |
| `VirtualTable.fts5(name, columns:, contentTable:, contentRowId:)` | Emits `CREATE VIRTUAL TABLE IF NOT EXISTS ... USING fts5(...)` with `content=`/`content_rowid=` args. Only `fts5` factory exists (`module` field notes fts4/rtree but no factories). |
| `Trigger(name:, timing:, event:, targetTable:, body:)` / `Trigger.ftsSync(...)` | `timing`: before/after/insteadOf; `event`: insert/update/delete. `body` is raw SQL inside `BEGIN ... END`. `ftsSync` builds an after-insert sync into an FTS table. |

## Instance management

Pure values — no instance to create beyond the `const Schema`, no
`dispose`, no connection held. Quoting is centralized (`_quote`: `"` → `""`).

## Behavior contracts

- Identifiers quote in exactly one place; `RawSql` never quotes. FK renders `REFERENCES "t"("c")` only when both ends set.
- `Table.toCreateTableSql()` always `IF NOT EXISTS`.

## Caveats / workarounds

- No column-type validation beyond what you declare: a `TEXT` column with `int` default emits `DEFAULT 1` unchecked — keep Dart-side and DDL types aligned.
- Virtual-table SQL is not quoted (`$name`, `$module` interpolated) and FTS options are positional strings — keep names alphanumeric; prefer the `fts5` factory over hand strings.
- Trigger `body` is unchecked raw SQL — a bad body fails at `migrate` time, not at declaration. Workaround: `plan()` first and inspect `steps[].sql`.
- Index renames are add-only: the differ creates missing indexes but never drops/renames — a renamed index leaves the old one behind. Workaround: drop manually or bump through a destructive path.
